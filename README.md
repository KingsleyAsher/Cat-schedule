# 日课 · 每日课表

彭茜雅的每日课表、月历课程总览及学期校历。

网站：https://kingsleyasher.github.io/Cat-schedule/

纯静态 HTML，支持手机和电脑。教学周按学校校历计算，以 2026 年 8 月 30 日为第一周起点。

界面默认使用深色模式，参考 [Kingsley 课表](https://github.com/KingsleyAsher/schedule) 的石墨灰卡片、蓝色高亮与课程分类配色。每日课表、月历总览、学期校历、手机导航及开场问候均已适配；`每日课表.html` 可单独下载使用。
